KI-Rechenleistung

          
Jede Aufgabe kann woanders laufen: lokal in LM Studio oder Ollama – oder auf einem schnellen Server im Heimnetz (jeder OpenAI-kompatible Server, z. B. LM Studio oder Ollama auf einem anderen Rechner). Lokales LM Studio / Ollama wird bei Bedarf automatisch gestartet.

          

          

        

        

          
Texterkennung

          
Analyse-Weg„Direkt“ schickt die Seiten als Bilder an das Analysemodell – ohne OCR. Braucht ein Modell, das Bilder versteht (z. B. Qwen 3.8 auf deinem Server).

            

          

          

          
Erste Wahl bei ScansPDF-Text wird immer zuerst direkt gelesen; fällt eine Erkennung aus, übernimmt die nächste

            

          
Eingebetteter PDF-TextTextschichten alter Scanner sind oft falsch. „Nur digitale PDFs“ nutzt exakten Text von Rechnungen, die direkt als PDF erstellt wurden.
